# StormOS Design Brief

## Identity

StormOS is the desktop environment of Thunderhead Pictures. It should feel
like standing inside a powerful thunderstorm: calm darkness, distant clouds,
electric energy, and cinematic light.

It must be an original interface. Do not copy the layout, icons, sounds, or
visual language of Windows, Linux, or macOS.

## Design principles

- **Cinematic:** spacious layouts, restrained motion, and dramatic lighting.
- **Storm-powered:** blue-white electricity is used only for important focus,
  active, and success states.
- **Calm, not noisy:** most of the screen stays dark and readable; lightning
  is an accent, never a distraction.
- **Solid and premium:** panels feel like dark glass and metal, not flat gray
  rectangles.
- **Original:** StormOS has its own shapes, menus, taskbar, and window chrome.

## Typography and icons

- Use **Segoe UI Variable** or **Inter** for a clean modern interface.
- Use one consistent outline-icon set; avoid emoji as permanent interface icons.
- Use bold, short headings and quiet secondary labels.

## Motion and effects

- Use soft fades, gentle panel slides, and brief electric-blue glows.
- Keep animation fast: about 150 to 300 milliseconds for normal actions.
- Never use flashing effects or constant lightning animation.
- Use a subtle rain, cloud, or lightning detail only in backgrounds and boot
  moments, where it does not interfere with reading.

## Screen direction

### Boot screen

A dark sky background, centered StormOS/Thunderhead logo, a single thin
electric progress line, and a quiet startup sound.

### Login screen

A blurred storm-cloud background. The login panel is dark translucent glass,
with a clear focused input glow and minimal controls.

### Desktop

A dramatic wallpaper with dark empty space for readability. Desktop items use
small storm-glass cards, not standard operating-system icons.

### Storm Dock

Instead of copying a Windows taskbar, use a low floating horizontal **Storm
Dock**. It has rounded storm-glass panels: a StormOS crest on the left,
active apps in the center, and time/status on the right.

### Command Center

Instead of a Start menu, use a centered **Command Center**. It presents a
search field, favorite apps, system actions, and recent work in a layered
storm-glass panel.

### App windows

Windows use dark glass, a thin blue edge when active, rounded corners, and a
compact header. The controls should be original icon buttons, not copied
Windows/macOS symbols or placement.
