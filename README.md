# StormOS

StormOS is an original, modern desktop environment created by Thunderhead
Pictures. It is built with Python and PySide6 and runs on top of an existing
operating system.

StormOS is currently in its early design and foundation stage.

## Vision

StormOS should feel cinematic, storm-powered, and original:

- Dark thunderstorm atmosphere with electric-blue accents
- A floating Storm Dock instead of a traditional taskbar
- A Command Center instead of a copied Start menu
- Security built into the project from the beginning
- No Tkinter; the interface is built with PySide6

## Project status

The original prototype is preserved locally in `backups/`. The active project
is being rebuilt cleanly in small, tested phases.

See [PLAN.md](PLAN.md) for the development roadmap and [DESIGN.md](DESIGN.md)
for the Thunderhead Pictures visual direction.

## Planned technology

- Python 3.13
- PySide6
- Windows-first development, with cross-platform support considered later

## Security note

Do not commit account data, passwords, local settings, virtual environments,
or private backups to this repository.
